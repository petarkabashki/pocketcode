# Product Context: Pocketcode

## Why This Project Exists

To create an open-source, highly extendable, and embeddable AI coding assistant named "Pocketcode". The goal is to combine the strengths of tools like Claude Code (strong coding capabilities) and Aider (agentic, iterative development) within a flexible framework.

## Problems It Solves

*   Lack of easily extendable open-source AI coding assistants.
*   Difficulty in integrating AI coding workflows into custom development processes.
*   Need for an AI assistant that can be easily customized with new tools (Python functions, MCP) and agentic behaviors (modes).

## How It Should Work (High Level)

*   Interact with users, likely through a CLI initially, potentially integrating with IDEs later.
*   Utilize the PocketFlow framework for managing workflows, modes, and tool usage.
*   Employ different agentic modes (Coder, Architect, etc.) for specialized tasks.
*   Allow developers to easily add new tools and capabilities.
*   Enable its core workflows to be embedded within other applications or larger systems.
